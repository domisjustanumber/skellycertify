# Reports

This folder holds each certify report that a reviewer committed from an issue. The path of a
report is `<name>/<yyyy>/<yyyymmddThhmmssZ>-<issue>.md`. For a report of the app, `<name>` is the
app name, for example `freemocap/2026/20261119T100000Z-12.md`. For a report of one package,
`<name>` is the package name. Each file is a byte copy of the file that the person sent.
A report that is valid as evidence and a report that is only a record are both here. The first
lines of each file tell which it is. The format is in [report-format.md](../report-format.md), and
the procedure is in [review.md](../review.md).
